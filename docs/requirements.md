# CookMate Requirements & V1 Scope

## 1. Product Statement
**CookMate** is an offline-first culinary companion app designed for chefs, home cooks, and food lovers to explore recipes from across the globe, bookmark favorites, cook with interactive step-by-step guidance and timers, and store personal kitchen creations.

---

## 2. Target Audience
- **Chefs & Professional Cooks**: Cataloging experimental dishes, personal variations, and precise timed instructions.
- **Home Cooks & Students**: Discovering simple and fast meals (<25 mins), tracking portion sizes, and following step-by-step guides.
- **Global Food Enthusiasts**: Exploring authentic dishes from Italy, India, Japan, Mexico, France, Thailand, and the Mediterranean.

---

## 3. Core Features Checklist
- [x] **100% Offline-First**: Zero backend dependency, instant local SQLite persistence.
- [x] **Dark Mode & Light Mode**: Seamless dynamic theme switching with rich culinary color palettes.
- [x] **Pre-seeded World Catalog**: Curated recipes from world-renowned chefs (Gordon Ramsay, Massimo Bottura, Vikas Khanna, Jiro Ono, Rick Bayless, Julia Child, etc.).
- [x] **Visual Category Browser**: Categories with custom color badges, icons, and recipe counters.
- [x] **Quick Launch Section**: Fast filtering for speedy recipes (<25 minutes).
- [x] **Multi-Criteria Search & Filter**: Real-time debounce query search across titles, ingredients, chefs, cuisines, difficulty levels, and prep times.
- [x] **Portion Scaling**: Interactive ingredient multiplier to scale ingredient amounts based on number of servings.
- [x] **Interactive Cooking Mode**: Distraction-free step guide with completion marks and integrated countdown timers.
- [x] **Pin Favourites**: One-tap bookmarking with reactive state across the app.
- [x] **Custom Recipe Builder**: Full CRUD support for creating and saving custom recipes offline.
